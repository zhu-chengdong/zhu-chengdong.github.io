SolidWorks AI

An AI application connecting structured design planning, native CAD execution and result verification.

FROM LANGUAGE TO CAD

  1. Requirement → structured design plan
  2. MCP → native SolidWorks API
  3. Geometry checks → previews + CAD files

Windows prerelease · SolidWorks 2024

The engineering task

A natural-language CAD tool needs to turn an incomplete request into a structured design, execute native CAD operations and inspect the resulting model. I developed the workbench and application workflow that connects these stages.

My implementation work

My work

  • Built model-provider adapters and a workbench for structured part and assembly planning.
  • Connected MCP tools to serial native SolidWorks API execution, with staged saving and revision tracking.
  • Integrated geometry checks and preview review; packaged native CAD, STEP, BOM and a Windows application.

Planning and review are separated from tool execution. Provider adapters connect OpenAI, DeepSeek and compatible interfaces; structured schemas restrict the supported geometry and request missing dimensions before execution.

MCP tools drive serial COM calls into SolidWorks 2024. The workflow reads actual geometry and assembly constraints, checks interference, saves and reopens documents, and verifies STEP exchange geometry.

The application tracks task revisions and preserves earlier files. Native CAD files, STEP, BOM, previews and dependent parts are collected into a delivery package; the Windows bundle includes its Python runtime.

An example workflow

  1. Describe a plate, L bracket or shaft, or provide existing SLDPRT parts and specify the required placement and mating relationships.
  2. Review the complete dimensional plan, then generate native parts or assemblies with coincident, distance or concentric mates.
  3. Inspect geometry results and previews, download the CAD delivery package, and create a new revision when parameters change.

Delivery and validation

A Windows x64 prerelease is publicly available. Local native-CAD checks cover SolidWorks 2024 part creation, saving, reopening, STEP export, previews and geometry reading. Automated regression and packaging checks support the release.

Another computer’s end-to-end model-to-CAD compatibility remains to be tested. Complex surfaces, manufacturing suitability and mechanical load capacity require separate engineering checks.
